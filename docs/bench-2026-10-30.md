# Graphics fixes and zoom investigation, 2026-10-30

## Outcome

- Roof rendering no longer performs its cursor spatial query when the hide-roof input is released. Real-game IL tests preserve the roof result for 3072 state combinations under each of en-US and ru-RU. The target and read-only dependencies are IL-pinned.
- RGB Max in PartMultiColor incorrectly reduced from negative infinity using Vector3.Min. The fix changes only that callback to Vector3.Max. Actual-component tests cover RGB/alpha/inversion modes, edge inputs, primary and buff sources, events and compatibility refusal. No vanilla Data rule in this install uses RGB Max; do not claim an FPS benefit from this correctness fix.
- The roof-only A/B does **not** establish an FPS improvement or close the release gate. No Workshop/GitHub publication is authorized by these results.

Each window measures at least 7200 physics ticks after 1200 warmup ticks; the physics rate is 30 ticks per simulated second.

## Fresh profile, excluded from A/B

`cpu-profile\results\586ece2c29a0af32.json.nettrace` samples 20 seconds of the baseline far scene. This is sampled thread wall time, not hardware CPU/GPU timing. On the main thread, about 66% falls under DoUpdate and 33% under DoDraw. Buffer.Memmove below D3D11 Draw/DrawInterleaved accounts for about 15.6%; per-frame blueprint port/toggle and smoothed-value updates are also significant. These are investigation targets, not sufficient proof of a safe replacement.

The repeated-color-write hypothesis was checked and rejected: ManagedShipQuad and the upstream graphics components already guard/coalesce unchanged finite colors. Changing NaN/equality or adding broad LOD was not justified.

Local analysis artifacts: `cpu-profile\main.speedscope.json` and `cpu-profile\main-thread-trimmed.txt`. Profiling perturbs the run; its frame metrics are excluded from the A/B table.
