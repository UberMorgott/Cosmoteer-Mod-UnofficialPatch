Unofficial Patch
[h1]Unofficial Patch[/h1]
[i]Community fixes for vanilla Cosmoteer: higher FPS and faster game speed in big battles, fewer stutters, fewer multiplayer desyncs. Ships, parts, balance and visuals stay vanilla.[/i]
[b]Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3577650065]Yet Another Mod Loader[/url].[/b] In multiplayer everyone needs the same version.
[b]Whole mod vs vanilla[/b], 40-ship battle, 60-second average: x1 18.4 → 28.9 FPS, game speed 12.9 → 17.5 steps/s; x8 7.6 → 21.2 FPS, slowest 1% of frames 276 → 133 ms; memory garbage -65%.
Screenshots: vanilla and the mod at the same simulation step of the same battle. Each shows the game's own FPS counter for that one frame and, separately, the 60-second average.

[h2]Performance, biggest gain first[/h2]
Before → after, 40-ship battle benchmark, each change measured alone on the test system below: approximate.
[list]
[*][b]Blueprint toggles[/b] re-checked on every part every frame; now only after a change. Close view 152 → 552 FPS, far 31.6 → 44.3, far x8 21.2 → 23.9.
[*][b]Adaptive game speed[/b] (single player, x2-x8): the game crammed up to 8 simulation steps into each frame; now only the steps that fit, so the game runs below the chosen speed instead of freezing. x8: 7.7 → 17.6 FPS, slowest 1% of frames 363 → 148 ms.
[*][b]Heat glows[/b] recoloured on every tiny change (~19,000 sprites per frame); now only per 1/255 colour step. Moving fleet 60.5 → 127.3 FPS, slowest 1% of frames 36.4 → 21.3 ms.
[*][b]Sprite uploads:[/b] one changed sprite re-sent a whole ship layer to the graphics card; now only the changed parts. Far 44.8 → 65.0 FPS, far x8 23.3 → 26.7 FPS, game speed 148 → 187 steps/s.
[*][b]Idle helper threads[/b] spun nonstop waiting for work; now they sleep and wake instantly. Processor time per simulation step -63%, game speed +5.4% (100 ships: -61%, +5.7%).
[*][b]Settled effect values[/b] (~92%) re-checked every frame; now they rest until changed. Close view 441 → 542 FPS, slowest 1% of frames 15.0 → 6.7 ms.
[*][b]Collision timing:[/b] every pass re-checked all ~4,900 contacts on one core; now all cores, later passes only the ~300 that changed. Its main-thread time -72%, processor time per simulation step -10%.
[*][b]Hull outline[/b] rebuilt after any destroyed part; now kept when it cannot change, neighbours read from a grid. Hull processor time -32%.
[*][b]Scene list removal[/b] compared thousands of objects one by one (~9% of the main thread); now by reference.
[*][b]Beams[/b] tested hundreds of their own ship's parts they can never hit; skipped. Main-thread time per simulation step -4%.
[*][b]Construction refresh[/b] ran for every destroyed part with nothing queued; skipped.
[*][b]Split decals[/b] looked up by name; now a table.
[/list]
All simulation changes together at x8: game speed 20.7 → 22.6 steps/s, frame spikes 52 → 30 per minute.

[h2]Less garbage, fewer stutters[/h2]
The game briefly pauses to clean up discarded memory (garbage); less garbage means fewer of these stutters. Garbage removed:
[list]
[*]Part toggles: ~430 MB per 20 s. Galaxy map labels: ~200 MB/20 s. Muted music decoding: ~190 MB/20 s (sound bit-identical). Thrusters: ~140 MB/20 s. Minimap particles: ~60 MB/20 s.
[*]Nebula checks with no nebula: ~136 MB per 3,000 simulation steps.
[*]Listener lists rebuilt for every destroyed part, sound or ship split: ~58 + 52 + 26 + 20 MB per 40 s battle.
[*]Shader values wrapped in temporary objects: garbage per frame -86%, cleanup pauses -59% (late-game save).
[*]Status effects left temporary lists behind every simulation step: cleanup pause time -4.6%.
[*]Roof hover search no longer runs while the hide-roof key is up; blueprint ports switch toggles directly.
[/list]

[h2]Bug fixes[/h2]
[list]
[*][b]Multiplayer desyncs:[/b] player money, station delivery missions and crew on another ship's job were changed from two threads at once. Now queued and applied in a fixed order.
[*][b]RGB Max[/b] colour blend used minimum and gave invalid colours.
[*]Network summary (freezes, input margin, ping) in the mod log every 10 s.
[/list]
