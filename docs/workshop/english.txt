[h1]Unofficial Patch[/h1]
Unofficial Patch is an attempt to speed up Cosmoteer and cure its ailments. It is made mainly to raise performance in single player and multiplayer. Bugs found along the way are fixed too, hence "unofficial patch". Ships, parts, balance and visuals stay vanilla.
[b]Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3577650065]Yet Another Mod Loader[/url].[/b] In multiplayer everyone needs the same version of the mod.

[h2]Performance[/h2]
Whole mod vs vanilla, 40-ship battle, 60-second average: normal speed 18.4 → 28.9 FPS; at x8 speed 7.6 → 21.2 FPS, worst frames 276 → 133 ms.
Fixes below, biggest gain first. Each was measured alone in the same battle on the test system below. All numbers are from a preliminary run and are approximate.
[list]
[*][b]Blueprint toggles:[/b] every frame, every ship re-checked the toggles of its parts, even when nothing had changed. Now this happens only after a change. Close view 152 → 552 FPS, far view 31.6 → 44.3 FPS, far view at x8 21.2 → 23.9 FPS.
[*][b]Fast speed in single player (x2-x8):[/b] when the computer could not keep up, the game squeezed up to 8 game steps into each frame and the picture nearly froze. Now each frame runs only as many steps as fit, so the game runs slower than the chosen speed but stays smooth. Multiplayer is not affected. At x8: 7.7 → 17.6 FPS, worst frames 363 → 148 ms.
[*][b]Heat glows:[/b] heat pipes, heat exchangers and radiators were recoloured on every tiny heat change, about 19,000 sprites per frame. Now a glow is recoloured only when its colour visibly changes (by one colour step). Moving fleet 60.5 → 127.3 FPS, worst frames 36.4 → 21.3 ms.
[*][b]Ship drawing:[/b] when one sprite of a ship changed, the whole ship layer was sent to the graphics card again (about 7 ms per frame with 40 ships in view). Now only the changed parts are sent. Far view 44.8 → 65.0 FPS, far view at x8 23.3 → 26.7 FPS.
[*][b]Idle helper threads:[/b] the game's helper threads kept the processor busy while waiting for work. Now they sleep and wake up the moment work arrives, leaving more processor power for the real work. The game runs a few percent faster.
[*][b]Heat effect values:[/b] radiator and heat exchanger effects were re-checked every frame, although most had already settled. Now settled values rest until something changes. Close view 441 → 542 FPS, worst frames 15.0 → 6.7 ms.
[*][b]Collisions of fast objects:[/b] after every bullet hit the game re-checked all of about 4,900 contacts on one processor core. Now the checks run on all cores, and repeat checks cover only the roughly 300 contacts that changed. Collision results are identical.
[*][b]Ship outline:[/b] after any destroyed part the ship's outline was rebuilt from scratch. Now it is kept when the destroyed part cannot change it, and the rebuild itself does less repeated work.
[*][b]Starting and stopping effects:[/b] when a sound, effect, beam or crew member started or stopped, the game searched a list of thousands of objects the slow way. Now it uses a much faster lookup.
[*][b]Beams:[/b] every beam tested hundreds of its own ship's parts that it can never hit. These parts are now skipped. Hits and damage are unchanged.
[*][b]Construction refresh:[/b] every destroyed part triggered a walk through the whole ship to refresh construction work, even with nothing queued. Now skipped when nothing is queued (about 1 ms per game step in a 40-ship battle).
[*][b]Decals on broken ships:[/b] when a ship broke apart, each decal was looked up by its name, letter by letter. Now a ready table is used (about 0.5 ms per game step in a 40-ship battle).
[*][b]Fewer short stutters:[/b] the game briefly pauses to clean up memory it no longer needs. Many places that kept creating throwaway data every frame or every step (part toggles, galaxy map labels, muted music layers, thrusters, minimap particles, nebula checks, status effects, ship breakups, sounds, drawing) now reuse it, so these pauses come less often. Music sounds exactly the same.
[/list]

[h2]Bug fixes[/h2]
[list]
[*][b]Multiplayer desyncs:[/b] player money, station delivery missions and crew working on another ship's job could be changed from two places at once, so players' games could drift apart. These changes are now applied one by one in a fixed order.
[*][b]RGB Max colour blend[/b] picked the smallest colour value instead of the largest and produced broken colours. Fixed.
[*]The mod log writes a short network summary every 10 seconds (freezes, ping per player) to help find the cause of multiplayer lag.
[/list]
