Unofficial Patch
[h1]Unofficial Patch[/h1]
[i]Community fixes for vanilla Cosmoteer: higher FPS and simulation speed in big battles, less stutter, fewer multiplayer desyncs. Ships, parts, balance and visuals stay vanilla.[/i]
[b]Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3577650065]Yet Another Mod Loader[/url].[/b] In multiplayer everyone needs the same version.
[b]Whole mod vs vanilla[/b], 40-ship battle (screenshots): x1 18.4 → 28.9 FPS, 12.9 → 17.5 ticks/s; x8 7.6 → 21.2 FPS, frame p99 276 → 133 ms; garbage -65%.

[h2]Performance, biggest gain first[/h2]
Before → after, 40-ship battle benchmark, each change measured alone on a busy dev PC (Ryzen 7 9800X3D): approximate. {NAME} = kill switch.
[list]
[*][b]Blueprint toggles[/b] re-checked on every part every frame; now only after a change. Close view 152 → 552 FPS, far 31.6 → 44.3, far x8 21.2 → 23.9. {BLUEPRINT_TOGGLE_SKIP}
[*][b]Adaptive tick budget[/b] (single player, x2-x8): the game crammed up to 8 ticks into each frame; now only the ticks that fit, so the game runs below the chosen speed instead of freezing. x8: 7.7 → 17.6 FPS, frame p99 363 → 148 ms. {TICK_BUDGET}
[*][b]Heat glows[/b] recoloured on every tiny change (~19,000 sprites per frame); now only per 1/255 colour step. Moving fleet 60.5 → 127.3 FPS, p99 36.4 → 21.3 ms. {GLOW_QUANTIZE}
[*][b]Sprite uploads:[/b] one changed sprite re-sent a whole ship layer to the GPU; now only changed ranges. Far 44.8 → 65.0 FPS, far x8 23.3 → 26.7 FPS and 148 → 187 ticks/s. {ATLAS_RANGE_UPLOAD}
[*][b]Idle helper threads[/b] spun nonstop waiting for work; now they sleep and wake instantly. CPU 308 → 114 ms per tick, ticks/s +5.4% (100 ships: 503 → 196 ms, +5.7%). {IDLE_PARK}
[*][b]Settled effect values[/b] (~92%) re-checked every frame; now they rest until changed. Close view 441 → 542 FPS, p99 15.0 → 6.7 ms. {SMOOTHED_ACTIVE_SET}
[*][b]Collision timing (TOI):[/b] every pass re-checked all ~4,900 contacts on one core; now all cores, later passes only the ~300 that changed. Its main-thread time -72%, CPU 116 → 104 ms/tick. {TOI_SCAN} {TOI_INCREMENTAL}
[*][b]Hull outline[/b] rebuilt after any destroyed part; now kept when it cannot change, neighbours read from a grid. Hull CPU -32%. {HULL_REMOVAL_SKIP} {BOUNDING_POINTS}
[*][b]Scene list removal[/b] compared thousands of objects one by one (~9% of the main thread); now by reference. {SCENE_BUCKET_REMOVE}
[*][b]Beams[/b] tested hundreds of their own ship's parts they can never hit; skipped. Main thread 16.1 → 15.5 ms/tick. {BEAM_OWN_SKIP}
[*][b]Construction refresh[/b] ran per destroyed part with nothing queued (~1.1 ms/tick); skipped. {CONSTRUCTION_FLOOD_SKIP}
[*][b]Split decals[/b] looked up by name (~0.5 ms/tick); now a table. {DECAL_LOOKUP}
[/list]
Tick changes together at x8: 20.7 → 22.6 ticks/s, frame spikes 52 → 30 per minute.

Garbage removed:

[*]Nebula checks with no nebula: ~136 MB per 3,000 ticks. {NEBULA_TEMPLIST}
[*]Listener lists rebuilt per destroyed part, sound or split: ~58 + 52 + 26 + 20 MB per 40 s battle. {DESTROYING_BODY_SUBSCRIBERS} {ZOOM_SUBSCRIBERS} {SOUND_STOP_HUB} {SPLIT_ALLOC}
[*]Shader value boxing: garbage per frame -86%, GC pauses -59% (late save).
[*]Status effects leaked temp collections every tick: GC pause -4.6%. {STATUS_TEMP_DISPOSE}
[*]Roof hover search with the hide-roof key up; blueprint ports use a direct toggle path.
[/list]

[h2]Bug fixes[/h2]
[list]
[*][b]Multiplayer desyncs:[/b] player money, station delivery missions and crew on another ship's job were changed from two threads at once. Now queued and applied in a fixed order.
[*][b]RGB Max[/b] colour blend used minimum and gave invalid colours.
[*]Network summary (freezes, input margin, ping) in the mod log every 10 s.
[/list]

[*][b]UNOFFICIAL_PATCH_BEAM_FROZEN=1[/b] (single player): ~11% faster combat ticks, but combat can differ from vanilla.
