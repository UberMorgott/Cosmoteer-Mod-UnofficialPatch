Unofficial Patch
[h1]Unofficial Patch[/h1]
[i]Фиксы сообщества для Cosmoteer: выше FPS и скорость симуляции в больших боях, меньше рывков и рассинхронов в сети. Корабли, модули, баланс и графика прежние.[/i]
[b]Нужен [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3577650065]Yet Another Mod Loader[/url].[/b] В сетевой игре у всех одна версия.
[b]Весь мод против ванили[/b], бой 40 кораблей (скриншоты): x1 18.4 → 28.9 FPS, 12.9 → 17.5 ticks/s; x8 7.6 → 21.2 FPS, кадр p99 276 → 133 мс; мусор -65%.

[h2]Производительность, по убыванию выигрыша[/h2]
До → после, бой 40 кораблей, каждое изменение отдельно, загруженный ПК (Ryzen 7 9800X3D): примерно. {NAME} = выключатель.
[list]
[*][b]Переключатели чертежа[/b] проверялись у каждого модуля каждый кадр; теперь лишь после изменения. Вблизи 152 → 552 FPS, издали 31.6 → 44.3, издали x8 21.2 → 23.9. {BLUEPRINT_TOGGLE_SKIP}
[*][b]Адаптивный бюджет тиков[/b] (одиночная игра, x2-x8): до 8 тиков в кадр; теперь сколько влезает: игра медленнее выбранной скорости, но не виснет. x8: 7.7 → 17.6 FPS, p99 кадра 363 → 148 ms. {TICK_BUDGET}
[*][b]Свечение нагрева[/b] перекрашивалось при любом изменении (~19,000 спрайтов за кадр); теперь шагом цвета 1/255. Флот в пути 60.5 → 127.3 FPS, p99 36.4 → 21.3 ms. {GLOW_QUANTIZE}
[*][b]Загрузка спрайтов:[/b] один изменённый спрайт пересылал на GPU весь слой корабля; теперь лишь изменённые части. Издали 44.8 → 65.0 FPS, издали x8 23.3 → 26.7 FPS и 148 → 187 ticks/s. {ATLAS_RANGE_UPLOAD}
[*][b]Простаивающие потоки[/b] крутились вхолостую; теперь спят и сразу просыпаются. CPU 308 → 114 ms на тик, ticks/s +5.4% (100 кораблей: 503 → 196 ms, +5.7%). {IDLE_PARK}
[*][b]Стабильные значения эффектов[/b] (~92%) проверялись каждый кадр; теперь ждут изменения. Вблизи 441 → 542 FPS, p99 15.0 → 6.7 ms. {SMOOTHED_ACTIVE_SET}
[*][b]Время столкновений (TOI):[/b] каждый проход проверял все ~4,900 контактов на одном ядре; теперь все ядра, поздние проходы лишь ~300 изменённых. Его время на главном потоке -72%, CPU 116 → 104 ms/tick. {TOI_SCAN} {TOI_INCREMENTAL}
[*][b]Контур корпуса[/b] перестраивался после гибели модуля; теперь хранится, если не меняется, соседи из сетки. CPU корпуса -32%. {HULL_REMOVAL_SKIP} {BOUNDING_POINTS}
[*][b]Удаление из списка сцены[/b] сверяло тысячи объектов поштучно (~9% главного потока); теперь по ссылке. {SCENE_BUCKET_REMOVE}
[*][b]Лучи[/b] проверяли сотни своих модулей, в которые не попадут; пропуск. Главный поток 16.1 → 15.5 ms/tick. {BEAM_OWN_SKIP}
[*][b]Обновление стройки[/b] шло на каждый уничтоженный модуль при пустой очереди (~1.1 ms/tick); пропуск. {CONSTRUCTION_FLOOD_SKIP}
[*][b]Декали раскола[/b] искались по имени (~0.5 ms/tick); теперь таблица. {DECAL_LOOKUP}
[/list]
Все изменения тиков на x8: 20.7 → 22.6 ticks/s, рывков 52 → 30 в минуту.

[h2]Меньше мусора, меньше рывков GC[/h2]
Убранный мусор:
[list]
[*]Делегаты переключателей модулей: ~430 MB за 20 с. Подписи карты галактики: ~200 MB/20 с. Декод заглушённой музыки: ~190 MB/20 с (звук бит в бит). Таблица двигателей: ~140 MB/20 с. Частицы миникарты: ~60 MB/20 с.
[*]Проверки туманности без туманности: ~136 MB за 3,000 тиков. {NEBULA_TEMPLIST}
[*]Пересборка списков слушателей (модуль, звук, раскол): ~58 + 52 + 26 + 20 MB за бой 40 с. {DESTROYING_BODY_SUBSCRIBERS} {ZOOM_SUBSCRIBERS} {SOUND_STOP_HUB} {SPLIT_ALLOC}
[*]Упаковка значений шейдеров: мусор за кадр -86%, паузы GC -59% (поздний сейв).
[*]Эффекты состояния теряли временные коллекции каждый тик: пауза GC -4.6%. {STATUS_TEMP_DISPOSE}
[*]Поиск крыши под курсором без нажатой клавиши; прямые переключатели портов чертежа.
[/list]

[h2]Исправления ошибок[/h2]
[list]
[*][b]Рассинхроны в сети:[/b] деньги игрока, задания станций на доставку и экипаж на задаче чужого корабля менялись из двух потоков сразу. Теперь очередь и фиксированный порядок.
[*][b]RGB Max[/b]: смешение цветов брало минимум и давало неверные цвета.
[*]Сводка сети (зависания, запас ввода, пинг) в логе мода каждые 10 с.
[/list]

[h2]Опции, по умолчанию выкл.[/h2]
[list]
[*][b]UNOFFICIAL_PATCH_SP_CATCHUP=1[/b] (сингл): возвращает время медленных кадров, держит полный x8 (242 vs 235 ticks/s) ценой части FPS.
[*][b]UNOFFICIAL_PATCH_BEAM_PARALLEL=1[/b]: попадания лучей на всех ядрах, результат точный; выигрыш пока не замерен.
[*][b]UNOFFICIAL_PATCH_BEAM_FROZEN=1[/b] (сингл): бой ~11% быстрее по тикам, но может отличаться от оригинала.
[*][b]Серверный GC:[/b] пустой файл [b]unofficial-patch-server-gc.txt[/b] рядом с Saved Ships, запуск игры, перезапуск (отмена: удалить). p99 кадра -18%, худший кадр +33%, больше RAM.
[/list]
В разработке: симуляция в отдельном потоке.

[h2]Безопасность[/h2]
[list]
[*]Сетевой хеш игры одинаков с каждым изменением симуляции вкл. и выкл. (3,000 тиков боя, 10 сетапов CPU/JIT, игра по LAN).
[*]Выключатель: переменная среды UNOFFICIAL_PATCH_{NAME}=0, перезапуск.
[*]Если обновление игры меняет исправленный код, мод выключается.
[*]Безопасно удалить: ни модулей, ни данных в сохранениях.
[/list]
